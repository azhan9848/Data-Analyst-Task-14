🧾 Superstore Sales Dashboard
📘 Project Overview

The Superstore Sales Dashboard is an interactive Power BI report designed to visualize and analyze sales performance across regions, product categories, and months.
The dashboard helps users quickly understand key trends in sales, profits, and regional performance, empowering data-driven decision-making for business growth.

🎯 Objective

To create a clean, interactive dashboard that shows sales performance by product, region, and month, with actionable insights for business users.

🧰 Tools Used

Power BI (Dashboard Creation)

Python (Pandas) (optional for data cleaning)

Dataset: Superstore_Sales.csv
(Columns: Order Date, Region, Category, Sales, Profit)

📂 Dataset Description
Column Name	Description
Order Date	The date when the order was placed
Region	Geographical area (North, South, East, West)
Category	Product category (Furniture, Technology, Office Supplies)
Sales	Total revenue generated
Profit	Profit made from sales
🧩 Dashboard Features
1️⃣ Monthly Sales Trend

A line chart visualizing sales across different months.

Helps identify high and low-performing months.

2️⃣ Sales by Region

A bar chart representing total sales per region.

Quickly identifies which region contributes the most to revenue.

3️⃣ Sales by Category

A donut chart showing percentage contribution of each product category to total sales.

Useful for category-level business strategy decisions.

4️⃣ Interactive Filters

Filters added for Region and Category for dynamic exploration of sales data.

📊 Key Insights

🏆 Technology category generated the highest sales (≈ 61.8% of total).

🌎 North Region recorded the highest revenue among all regions.

📅 April 2023 showed the peak sales month, indicating a strong seasonal performance.
